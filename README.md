# 小米智能存储下载中心

插件版本 **1.0.8**。使用独立 aria2 核心，提供直链、磁链和 BT 下载；不是迅雷官方客户端，不提供会员、离线加速或资源解析。

## 本版界面更新

统计信息使用共用背景与细分隔线，不再使用独立大卡片；手机按内容显示紧凑单行或两行，电脑优先单行。Docker 统计保留点击跳转，定时任务仅在失败数非零时强调，文件快传在记录页标题旁显示计数。

统一六插件的页头位置、状态卡片、统计信息顺序、圆角、间距和刷新按钮。电脑客户端随窗口使用全部可用宽度，手机页头显示当前插件名称，浅色使用雾灰背景，手机深色使用中性炭灰。样式限定在插件内部，不修改客户端全局字体；保留原有配置和功能。

## 功能

- HTTP / HTTPS / FTP / SFTP 直链；批量链接最多 20 条。
- BT v1 磁链、普通/混合 `.torrent` 种子（最大 4 MiB、导入时最多 2000 个文件）。纯 BT v2 暂不支持。
- 下载队列、搜索筛选、进度、速度、剩余时间估算、做种状态、暂停/继续、队首调整、失败重试。
- 种子导入时勾选文件；磁链获取元数据后暂停，再进入详情选择文件。
- 后台执行全部暂停/继续及历史清理，不使用阻塞整个页面的等待窗口。
- 删除单个任务时可勾选“同时删除已下载和未完成文件”，默认不勾选。清空历史仅移除记录。
- 并发数、连接数、上传/下载总限速、做种时间和分享率设置。
- Tracker 手动列表、最多 3 个 HTTP/HTTPS 订阅、一键更新、去重、每天自动更新（默认关闭）、应用到进行中的 BT 任务。
- 每用户独立进程、端口、密钥、配置和记录，不依赖 Docker、不复用 Openlist 服务、不需要额外 root 权限助手。

## 下载目录

创建任务时点击“下载到”，在居中弹窗中选择当前用户“我的文件”里的目录。支持树形展开/折叠、默认/最近目录定位，以及在树中输入名称并点击 ✓ 创建文件夹。点击“新建文件夹”或仅输入名称不会创建目录，点击 × 取消也不会创建。后端拒绝绝对路径、`..` 和符号链接，不能选择系统目录、其他用户文件区或共享给我的目录。

直链直接下载到所选目录，不创建编号子目录。BT / 磁链创建与资源名称对应的文件夹，避免重复嵌套同名层级；磁链先在插件私有目录获取元数据，校验后才开始写入用户目录。同名文件或文件夹会加 `(1)`、`(2)` 等后缀，保留已有内容。任务卡片显示实际位置。

删除文件按任务登记的目录和文件名定位，不比较 inode 或设备号。仍禁止越出当前用户空间、跟随符号链接或递归删除整个目录；未登记的文件与非空子目录保留。如果同名文件已被替换，也会按登记路径删除，请在删除前确认。文件删除失败仍移除任务记录并提示残留；任务必须先成功停止。删除文件不能撤销。

## 安装 / 更新 / 卸载

保留完整目录结构：`manage.sh`、`payload/`、`README.md` 和 `THIRD_PARTY_NOTICES.md`。统一入口：

```bash
bash manage.sh
# 或
bash manage.sh install
bash manage.sh uninstall
```

- NAS 本机：自动识别，以 root 运行安装器。下载服务始终以所选普通用户身份运行。
- WSL / Linux：自动通过 root SSH 连接，交互询问设备 IP；不写死 IP 或账户。
- 安装和卸载均扫描用户，支持单选、逗号多选或 `all`。只操作所选用户。

```bash
bash manage.sh install --ip 192.168.31.100 --users u123456789
bash manage.sh install --all-users
bash manage.sh install --list-users
bash manage.sh install --all-users --dry-run
bash manage.sh uninstall --users u123456789 --yes
```

本机执行时省略 `--ip`；远程非交互执行需要 SSH 密钥。安装前必须已初始化用户并正常挂载存储池。安装器要求 ARM64、Python 3.8+（含 sqlite3）、jq、runuser、flock、ss 和设备原有 plugincenter。

首次安装自动下载固定版本 **aria2 1.37.0 ARM64 静态构建**，核对固定 SHA-256 后提取核心。第三方构建来源见许可说明，校验失败不会安装。GitHub 网络受限时可预先下载指定 ZIP，再离线安装：

```bash
DOWNLOADCENTER_CORE_ARCHIVE=/你的路径/aria2-aarch64-linux-musl_static.zip bash manage.sh install
```

指定的离线 ZIP 同样必须通过固定哈希校验，不接受随意替换的可执行文件。文件下载在执行安装的电脑/WSL或 NAS 本机进行，可按环境设置 `https_proxy`。

更新保留配置、队列和记录；原来停用的服务保持停用。卸载会停止所选用户服务，移除网页注册、用户专属定时项及程序，但不删除任何下载文件。配置和记录先备份到：

```text
/home/<用户>/plugin/.reserve/downloadcenter/<时间>-<进程号>/
```

备份可能含私密下载链接、种子和控制密钥，不应公开。其他用户仍在使用时保留共用图标。

## 启动与端口

- 安装和网页部署使用小米系统一致的完整目录 SHA-256 摘要；安装结束调用系统校验，避免重启时因摘要不一致被强制卸载。请勿直接修改已安装的 `src` 内容而不更新 `INFO.abstract`。
- 内置 aria2 位于 `src/files/aria2c`；网页更新的核心位于 `var/core/aria2c`，优先使用并在重装时保留，不改动受校验的源码目录。
- RPC 控制接口仅监听本机，端口从 `19300–19399` 分配，每用户独立密钥；不要将 RPC 映射到公网。
- BT TCP/UDP 端口从 `19400–19499` 分配，具体值安装结束显示，也保存在 `var/peer.port`。需要更好的入站连通性时，可自行转发该用户 BT 端口，不是网页/RPC 端口。
- 安装创建 `/etc/cron.d/downloadcenter-<用户>`，每分钟以普通用户检查下载服务。只在存储池已挂载且服务处于启用状态时启动。
- 手动停止服务后保持停止；重启后最多等待约一分钟恢复。运行中检测到存储池未挂载会停止核心。正常停机会保存队列；异常断电仍可能丢失最近约 15 秒的核心会话变化。
- 暂停任务在重启后保持暂停。已完成/失败记录独立保存在 SQLite，不依赖核心内存历史。

## UI

沿用现有插件的雾蓝灰背景、浅色卡片、电脑侧栏、手机标签页和左右滑动切页；显示插件版本号。手机跟随 Android / iOS 系统深色偏好，电脑客户端保持与现有插件一致的浅色方案。

目录选择和确认框都是网页内的居中圆角弹窗；无原生 select/confirm。弹窗打开时锁定背景滚动，二级弹窗遮蔽下层弹窗，动作按钮就地转圈。小窗口独立滚动到底，高分辨率不使用 CSS zoom。

## 限制与注意

- 断点续传取决于服务器能力和 `.aria2` 文件；失败重试沿用同一任务目录。
- 不支持迅雷专有协议、ed2k、网盘解析、Cookie/登录下载、自动解压或媒体转码；SFTP 需要核心和服务器兼容，第一版不提供账户密码输入。
- 默认上传限速 1024 KiB/s；下载不限速；并发 3；做种最长 60 分钟或分享率达到 1。Tracker 不保证无种资源可以下载。
- 为安全起见，直链下载的 `.torrent` / Metalink 不自动执行，需显式导入种子。
- 默认不内置公共 Tracker，不将私人种子信息主动发送给预设第三方。自行添加的 Tracker 可能接收任务信息，请勿给私有种子添加不可信 Tracker。
- 最多保留 1000 条任务，种子及链接元数据合计不超过 64 MiB。
- 所有网页操作仍依赖小米客户端的用户认证；本插件不提供独立公网管理页面。

## 日志与本地验证

日志在 `/home/<用户>/plugin/downloadcenter/var/`：`service.log`、`aria2.log`、`control.log`。其中链接或文件名可能含隐私，请脱敏后分享。

源码仓库的 `tests/test_download_center.py` 覆盖路径越界、符号链接、删除保护、种子解析，并可通过 `--engine /path/to/aria2c` 运行真实核心的本地 HTTP 下载和队列测试。`tests/download-preview.cjs` 使用模拟 API 检查页面布局与交互，不代表真实手机 APP 已实机验证。

请仅下载有权获取和分享的内容。

### 1.0.3 界面与种子导入更新

- BT 种子可从本机上传，或浏览当前 NAS 用户的「我的文件」选择；最大 4 MiB，支持预览并勾选下载内容。
- NAS 浏览仅显示文件夹和 `.torrent` 文件；禁止符号链接及跨用户路径，导入不会移动或删除原种子。
- 文件选择和刷新按钮改用统一圆角样式，兼容电脑布局及手机深色模式。
- 修复电脑客户端合法跨源请求被误拦截；仍由 NAS 插件网关鉴权，aria2 RPC 保持仅本机访问。

### 1.0.4 更新

- Tracker 按 URL 独立缓存，失败源保留旧列表，成功源正常更新；跳过不支持或无效的地址，并显示各源错误、跳过数量与保留数量。合并后最多 500 个，优先保留手动列表。
- 设置页支持 aria2 版本检查、下载更新、SHA-256 与架构校验及启动失败回退。使用同一第三方静态构建渠道，不冒充官方 Linux 二进制；可勾选本机 Mihomo HTTP 代理 127.0.0.1:7890。切换时保存会话并短暂重启下载服务，任务和设置保留。插件重新安装会保留比内置版本更新的核心。
- 各插件样式和 DOM 操作限定在自己的根容器，不再修改电脑客户端的 html/body、字体或外部控件；电脑滚动与手机深色模式保持兼容。
- 删除按文件名和目录执行；文件清理失败仍移除任务记录并提示残留。原有失败记录不会自动清理，需手动再次删除。

### 1.0.5 删除清理

- 删除任务时清理其私有目录内自动生成的磁链种子与对应临时文件；手动导入的原始种子不受影响。
- 勾选同时删除文件后，按任务记录删除下载文件和续传文件，再自内向外删除任务创建的空文件夹。非空文件夹及用户选择的上级目录保留，不递归清空下载目录。
- 未勾选时保留下载内容，仅清理任务记录和自动生成的种子缓存；删除失败仍移除记录并提示残留。历史残留不会自动扫描或清理。

### 1.0.6 种子副本与文件列表

- 删除任务时同时清理 aria2 在该任务下载目录内生成的种子副本：RPC 上传按种子全文件 SHA-1 命名，磁链元数据按 infoHash 命名；兼容从旧任务保存的种子内容计算文件名。不关闭 aria2 元数据持久化，保留重启恢复能力。
- BT 文件选择改为按子目录分组，行内只显示文件名、大小与详情中的进度，支持全选和反选。详情每页 200 项，保留跨页选择；运行中的任务需先暂停再改选。
- 设置页新增「清理磁链缓存」。确认后只清理插件 `var/metadata` 内已无任务使用、命名符合规范的自动种子及对应临时文件；显示文件数、释放空间及保留/失败情况。
- 清理前核对任务库和 aria2 队列，保留解析中、下载中、暂停及历史任务的缓存；核心无法连接时拒绝清理。保留未知文件、符号链接、DHT 数据、续传文件及用户导入的原种子，不扫描下载目录。
- 已删除记录的旧任务无法可靠还原其下载目录与种子归属；旧版本留在下载目录内的种子不会被缓存按钮全盘扫描删除，需确认后手动处理。

### 1.0.7 详情边界修复

- 超长任务标题限制为两行，关闭按钮保持在弹窗内部；目录、错误说明支持长文本换行。
- 文件列表补齐网格与弹性布局的宽度约束，文件名在本列省略，大小和进度列不被挤出边界。兼容电脑小窗口和手机浅色/深色布局，不改动实际文件名或下载任务。
