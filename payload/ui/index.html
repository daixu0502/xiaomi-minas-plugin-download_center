限速 0 表示不限速。默认上传限制 1024 KiB/s，避免占满带宽。每核心限速立即应用；两个核心同时工作时合计可能达到两倍配置值。做种设置主要用于新任务；Openlist 共用对应核心的带宽与连接上限。

BT 网络与节点发现

首次切换默认仅使用 IPv4，IPv6 可手动开启。保存后再确认重启当前用户下载核心应用；不重启 NAS。qBittorrent 的 DHT 同时作用于已启用的 IPv4 / IPv6，不提供独立 IPv6 DHT 开关。

连接数并非越多越好，提高后可能增加内存、CPU 和路由器负担。私有种子由核心禁用 DHT / PEX，插件不会给私有种子追加公共 Tracker。

Openlist 接入

将 Openlist 的 BT／磁链交给本插件。默认通过本机连接；启用局域网接口后，也支持 bridge 网络容器。

连接地址包含密码，仅在需要时显示，请勿分享截图。接口仅用于可信内网，请勿转发到公网。

目录与任务说明

兼容接口把容器临时目录转换到当前用户的下载目录。Openlist 和 qB 必须能访问同一批文件，不能只改一侧路径。

仅展示和操作 Openlist 自己的任务。两者共用 BT 带宽与连接上限；停止或更新下载核心时，Openlist 下载也会短暂中断。

缓存清理

清理插件内已无任务使用的磁链种子和临时缓存。保留正在下载、解析、暂停及历史任务的缓存，不删除下载内容、手动导入的种子、续传文件或 DHT 数据；不扫描下载目录。需保持下载服务运行以核对占用。

协议与边界

HTTP / HTTPS / FTP / SFTP 直链，BT v1 磁链与 .torrent 文件；不支持 ed2k、迅雷专有链接、网盘解析或会员离线加速。BT v2 纯种子暂不支持。

只下载有权获取的内容。直链下载 .torrent 文件不会自动开始 BT 下载，请将种子导入本插件。带鉴权的网站、Cookie 下载和自动解压暂未提供。
